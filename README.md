# منصة الجالية السورية في هولندا | Syrian Community in the Netherlands (SGN)

منصة رقمية متكاملة تهدف لخدمة وتيسير شؤون الجالية السورية في هولندا، وربط الأعضاء ببعضهم البعض، ومشاركة الأخبار والفعاليات، والفرص التطوعية، مع تطبيق هاتف ذكي مرافق (Mobile App).

## 🏗 هيكلية المشروع (Project Structure)

يتكون المشروع من قسمين رئيسيين:
1. **تطبيق الويب (Web App)**: لوحة تحكم متكاملة وموقع تفاعلي مبني باستخدام Next.js 16 (App Router + React 19).
2. **تطبيق الموبايل (Mobile App)**: تطبيق تفاعلي للأعضاء مبني باستخدام Expo React Native.

```text
SGN/                          # ← تطبيق الويب (Next.js 16 + i18n + Tailwind)
  src/
    app/                      # المسارات والصفحات والمنافذ البرمجية (API Routes)
    components/               # عناصر الواجهات المشتركة (React Components)
    lib/                      # المكتبات والخدمات (AI, Prisma, Sync, RAG)
    messages/                 # ملفات الترجمة للويب (ar.json, en.json, nl.json)
  mobile/                     # ← تطبيق الموبايل (Expo React Native)
    app/                      # شاشات التطبيق الرئيسية (Tabs, Vault, Chat)
    constants/                # الإعدادات والثوابت وروابط الخادم (config.ts)
    i18n/                     # ملفات الترجمة للموبايل (ar.json, en.json, nl.json)
    lib/                      # محرك الترجمة والاتصال بالخادم
  prisma/                     # قاعدة البيانات (Prisma Schema v7 & Migrations)
  scripts/                    # أدوات المزامنة والصيانة ولوحة التحكم
```

## ⚡ الميزات الرئيسية (Key Features)

* **الأخبار والفعاليات**: تصفح وتصنيف الأخبار (أخبار الجالية، هولندا، أوروبا، اقتصاد، ثقافيات) مع قسم مخصص للفيديوهات ومعرض الصور والمزامنة من Facebook و YouTube.
* **إدارة العضويات وبطاقة العضوية الرقمية**: نموذج انتساب ذكي يتيح للأعضاء التسجيل وتوليد بطاقة عضوية رقمية تدعم التحقق الفوري عبر رمز الـ QR (متوفر في الويب والموبايل).
* **المخزن الآمن وتحليل المستندات (Vault)**: حفظ مستندات الإقامة والخطابات الرسمية بشكل آمن مع تحليل بالذكاء الاصطناعي باللغة العربية لشرح الإجراءات والجهات الحكومية (IND, Belastingdienst, Gemeente, CJIB).
* **الربط الذكي للتطوع (AI-Skill Matcher)**: تحليل مهارات العضو واقتراح المهام والفرص التطوعية المناسبة له بدقة.
* **دليل الخدمات المهنية (Services Directory)**: يتيح للكفاءات السورية (مهن حرة، حرفيين، مترجمين، مستشارين) عرض خدماتهم والتواصل المباشر مع المجتمع.
* **المساعد الذكي متعدد المزودين (Multi-Provider AI)**:
  - دعم **Groq AI** السريع والمجاني (Llama 3.3 70B).
  - دعم **Ollama** محلياً (`qwen2.5:7b` للنصوص و `llava:7b` لقراءة الهويات والمستندات).
  - دعم **Anthropic Claude** و **OpenAI**.
  - تقنية RAG للبحث الدقيق في قاعدة بيانات الجالية (الأخبار، الفعاليات، المتطوعين، الأعضاء).
* **المراسلة المباشرة والإشعارات (Direct Chat & Push Notifications)**: تواصل فوري بين الأعضاء ومقدمي الخدمات مع إشعارات Expo Push على الموبايل.
* **مجلس الإدارة**: صفحة رسمية معتمدة تضم أعضاء مجلس الإدارة الـ 24 بصورهم الرسمية ومعلوماتهم.

## 🔒 قاعدة العزل اللغوي الصارم والمطلق

* **القسم العربي (`/` أو `/ar`)**: أحرف عربية نقية، أرقام مشرقية عربية ناصعة (`١، ٢، ٣...`) في كافة أرجاء الموقع، خط `Almarai` العربي النقي.
* **القسم الإنجليزي (`/en`)**: أحرف إنجليزية فقط وأرقام لاتينية (`1, 2, 3...`).
* **القسم الهولندي (`/nl`)**: أحرف هولندية فقط وأرقام لاتينية (`1, 2, 3...`).

## 🛠 التقنيات المستخدمة (Tech Stack)

* **Next.js 16** (App Router & React 19)
* **React Native & Expo 54** (لتطبيق الموبايل)
* **TailwindCSS** (للتنسيق البصري للويب)
* **Prisma ORM v7** (مع SQLite محلياً و Turso/libsql للإنتاج)
* **Next-Auth** (إدارة الجلسات والصلاحيات)
* **AI Engine**: Groq, Ollama, Anthropic Claude, OpenAI مع محرك RAG المخصص.
* **Next-Intl & Mobile useI18n** (دعم كامل للعربية، الهولندية، والإنجليزية مع ملاءمة RTL/LTR)

## 🚀 تشغيل وتطوير المشروع (Local Development)

### 1. إعداد تطبيق الويب (Next.js)

```bash
# تثبيت الاعتماديات
npm install

# توليد عميل Prisma ومزامنة قاعدة البيانات المحلية
npm run db:push

# تشغيل خادم التطوير التجريبي
npm run dev
```
* سيعمل الموقع على الرابط: `http://localhost:3000`

### 2. إعداد تطبيق الموبايل (Expo)

```bash
cd mobile
npm install

# للربط مع السيرفر المحلي
npm run set:dev
npm start

# أو للربط مع السيرفر الحي المباشر (Vercel)
npm run set:prod
```

## 🧰 أدوات المساعدة ولوحة التحكم (Helper Scripts & Tools)

يوفر المشروع مجموعة متكاملة من الأدوات والملفات المساعدة لتسهيل الإدارة والصيانة:

* **`sgn.bat`**: لوحة التحكم الشاملة (تشغيل بيئة العمل، مزامنة Git، نشر Vercel، بناء الموبايل، تحديث قاعدة بيانات Turso).
* **`sync-and-deploy.bat`**: سحب أحدث التعديلات، فحص i18n، وعمل commit & push للنشر الفوري.
* **`scripts/09-sync-live.ts`**: إرسال أمر مزامنة فوري لجلب المقالات وحفظها في الموقع الحي.
* **`scripts/windows/full-clean-and-audit.bat`**: تنظيف الملفات المؤقتة وفحص سلامة الـ TypeScript للويب والموبايل.
* **`scripts/windows/mobile-build-prod.bat`**: تجهيز بيئة الإنتاج وبناء تطبيق الموبايل (APK / iOS / Web).
